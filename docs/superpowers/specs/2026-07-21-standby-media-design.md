# 待机媒体播放设计

**日期：** 2026-07-21  
**状态：** 已获设计批准，等待文档审阅

## 目标

当应用在指定时间内没有用户输入时，进入全屏待机界面，并从用户在设置页选择的目录中按文件名顺序循环播放图片和视频。任意鼠标或键盘输入都会立即关闭待机界面并重新开始计时。

## 已确认的需求

- 默认无操作超时值为 60 秒，用户可在设置页修改为任意正整数秒。
- 用户在设置页选择媒体目录。
- 媒体按文件名升序循环。
- 视频静音播放。
- 鼠标移动、鼠标点击、鼠标滚轮和键盘输入都会退出待机。

## 方案选择

采用 Python 控制器配合 QML 全屏覆盖层。

Python 负责设置持久化、目录扫描、文件过滤和向 QML 提供媒体 URL。QML 负责无操作计时、显示覆盖层、图片/视频切换和输入处理。该划分避免在 QML 中直接访问文件系统，并使扫描、排序和配置行为可由 Python 测试覆盖。

不采用纯 QML 方案，因为其目录枚举和可测试的持久化能力不足；不采用外部播放器方案，因为它不能可靠地覆盖当前界面并在任意输入时返回。

## 架构

### `StandbyMediaController`（Python）

新增 QObject 控制器，注册为 QML 上下文属性 `standbyMediaController`。其职责为：

- 读取并保存待机配置：`mediaDirectory` 与 `idleTimeoutSeconds`。
- 默认超时值为 60 秒；只接受正整数，非法值保留当前有效值。
- 扫描所选目录的直接文件，按文件名排序，过滤支持的图片和视频扩展名。
- 向 QML 暴露配置、扫描结果、媒体 URL 列表、有效媒体数量和可读错误信息。
- 在保存目录或超时值时立即刷新状态；QML 也可显式请求刷新。

配置保存在应用的用户配置目录中，使用单个 JSON 文件。启动时配置文件缺失、格式错误或内容无效时，控制器以默认值和空目录安全启动，并报告可显示的提示，不让应用启动失败。

### 设置页

在现有“设置”中增加“待机动画”子页。页面包含：

- 目录选择按钮和当前目录文本。
- 秒数输入控件，最小值为 1，初始值为 60。
- 已发现媒体数量与扫描状态/错误提示。

保存动作会调用控制器并立即刷新扫描结果。设置页不复制媒体列表或持久化逻辑。

### QML 待机覆盖层

主 `ApplicationWindow` 包含一个默认隐藏的全屏覆盖层：

- 普通状态下，单次 `Timer` 在 60 秒（或配置值）后触发。
- 全局鼠标移动、点击、滚轮和按键输入会重启计时器；如果待机层可见，则先隐藏待机层。
- 只有控制器报告至少一个有效媒体时才允许显示待机层。
- 覆盖层为不透明黑色，并按控制器提供的顺序播放媒体。
- 图片使用 `Image` 等比完整显示；视频使用 QtMultimedia 的 `MediaPlayer` 和 `VideoOutput`，强制静音，在结束时转到下一项。
- 图片采用固定展示时长；实现时将该时长定义为单一常量，默认 10 秒。
- 媒体加载或播放失败时跳过该项，继续下一项，避免待机层卡住。

## 数据流

1. 应用启动时，控制器加载并验证持久化配置，扫描配置的目录。
2. 用户在待机动画设置页选择目录或修改秒数，控制器保存配置并重新扫描。
3. 控制器将排序后的本地媒体 URL、数量和错误信息通过 Q_PROPERTY/信号提供给 QML。
4. 主窗口收到输入时重启无操作计时器；计时器触发时检查媒体列表。
5. 目录中有可用媒体时，显示待机层；播放器按索引播放，末项后回到第一项。
6. 新的用户输入关闭待机层，停止视频并重新开始倒计时。

## 支持格式与异常处理

初始实现支持以下常见扩展名（不区分大小写）：

- 图片：`.bmp`、`.gif`、`.jpeg`、`.jpg`、`.png`、`.webp`
- 视频：`.avi`、`.mkv`、`.mov`、`.mp4`、`.m4v`、`.webm`

控制器只收录普通文件，不递归扫描子目录。不存在、不可读或无有效媒体的目录均不会触发待机层，并在设置页显示原因。个别媒体无法由平台解码时，QML 跳过该文件并继续循环；这不会改变已保存的目录配置。

## 测试策略

- Python 单元测试：默认值、配置加载/保存、无效配置回退、目录过滤、文件名排序和目录错误。
- QML 组件测试：主窗口包含待机计时器和覆盖层；输入重置计时器；无媒体时不显示覆盖层；媒体索引循环；视频静音属性。
- 集成验证：在 offscreen Qt 平台加载主 QML，确认新增组件没有 QML 加载错误。

## 非目标

- 不递归读取子目录。
- 不提供随机播放、播放列表编辑或每个文件的单独时长设置。
- 不播放视频声音。
- 不在本次改动中实现远程媒体、网络流或外部播放器。
